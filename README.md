## Deskripsi

Project ini merupakan Tugas Rutin 8 pada mata kuliah Pemrograman Web.
Project dibuat menggunakan PHP Native dan MySQL dengan menerapkan operasi CRUD
(Create, Read, Update, Delete).

## Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- XAMPP

## Fitur

- Menampilkan data
- Menambahkan data
- Mengubah data
- Menghapus data
- Koneksi PHP dengan MySQL

## Struktur File

| File | Fungsi |
|---|---|
| `index.php` | Halaman utama |
| `data.php` | Menampilkan data |
| `Create.php` | Form untuk menambahkan data |
| `proses_create.php` | Memproses penambahan data |
| `update.php` | Form untuk mengubah data |
| `proses_update.php` | Memproses perubahan data |
| `delete.php` | Menghapus data |
| `koneksi.php` | Menghubungkan PHP dengan database MySQL |
| `database.sql` | File database |
| `style.css` | Mengatur tampilan website |
